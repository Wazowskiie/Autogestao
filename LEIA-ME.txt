VENDAS COMPLETAS
================

O que entrou
1. Despesas da venda: transferência, vistoria, brinde... entram no Financeiro e saem do lucro.
2. Financiamento: banco, situação da ficha (em análise, aprovada, recusada, paga) e retorno do banco.
   Quando marcar "Paga pelo banco", o valor e o retorno ficam como recebidos no Financeiro.
3. Pós-venda: ATPV-e, comunicação de venda, transferência (prazo de 30 dias), chave reserva,
   manual e documentos. Aviso no topo de Vendas com as transferências pendentes e atrasadas.
4. Garantia por venda (dias + o que cobre) e 3 documentos novos: Termo de garantia,
   Termo de entrega e Recibo.
5. Cancelar venda (distrato): a venda fica no histórico como cancelada, o veículo volta ao
   estoque, o que não foi recebido sai do Financeiro e o valor devolvido vira despesa.
   "Excluir" continua existindo, só para venda lançada errado ou de teste.
6. Reserva com sinal: botão roxo no Estoque. Na venda, o cliente e o sinal já vêm preenchidos.
7. Comissão do vendedor em cada venda (% cadastrada no vendedor sobre o preço), com
   "a pagar / paga". Aparece também na tela de Vendedores.
O lucro de cada venda agora é o lucro real: preço − custo − taxa de cartão − despesas − comissão + retorno.
As vendas antigas continuam com o lucro que tinham.

1) COPIE OS ARQUIVOS
Copie as pastas autogestao-backend e autogestao-frontend deste zip por cima das suas.
Atenção: o schema.prisma vai inteiro (mudou em vários lugares). Se você tiver mexido nele
por conta própria depois da última vez, me avise antes de substituir.

2) NO SEU PC, DENTRO DA PASTA autogestao-backend
  cd autogestao-backend
  npx prisma migrate deploy
  npx prisma generate
  (Se aparecer "Need to install the following packages", responda n: você está na pasta errada.)

3) COMMIT E PUSH (pelo VS Code)

4) NO VPS
  cd /var/www/Autogestao
  cp -r autogestao-backend/storage ~/storage-backup
  git pull origin main
  cp -rn ~/storage-backup/. autogestao-backend/storage/
  cd autogestao-backend
  npm install
  npx prisma migrate deploy
  npx prisma generate
  npm run build
  cd ../autogestao-frontend
  npm install
  npm run build
  pm2 restart all
  Depois Ctrl+Shift+R no navegador.
