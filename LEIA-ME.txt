WHATSAPP OFICIAL + REDES SOCIAIS
================================

O que entrou
1. Configurações → Loja → "WhatsApp e redes sociais": WhatsApp da loja, Instagram,
   Facebook, TikTok, YouTube e outro site (pode colar o link ou só o @).
   - Aparecem como ícones no topo e no rodapé do seu site.
   - Os botões "WhatsApp" do site passam a usar esse número.
   - Mensagens prontas do CRM ganham {instagram} e {whatsapp_loja}.
2. Configurações → Integrações → "WhatsApp oficial (Meta)": conexão com a API oficial.
   - Cada mensagem que chegar vira lead no CRM (origem WhatsApp), entra no rodízio
     e cria a tarefa "Responder (WhatsApp)".
   - No lead, aba "WhatsApp": a conversa e a caixa para responder pelo sistema.
   - O card do lead mostra "X mensagens novas no WhatsApp".
   - Regra da Meta: só dá para responder pelo sistema até 24h depois da última
     mensagem do cliente. Depois disso, o sistema oferece o WhatsApp normal.

1) COPIE OS ARQUIVOS por cima dos seus.
   Vão inteiros: schema.prisma, main.ts, app.module.ts (já com os Anúncios),
   Settings.tsx e PublicStorefront.tsx.

2) NO SEU PC, dentro de autogestao-backend
   npx prisma migrate deploy
   npx prisma generate
   npm run build

3) COMMIT E PUSH. Mensagem sugerida:
   WhatsApp oficial (Meta) no CRM e redes sociais da loja

4) NO VPS
   cd /var/www/Autogestao
   cp -r autogestao-backend/storage ~/storage-backup
   git pull origin main
   cp -rn ~/storage-backup/. autogestao-backend/storage/
   cd autogestao-backend
   grep -E "PUBLIC_API_URL|TOKEN_ENCRYPTION_KEY" .env | cut -d= -f1
     (tem que aparecer as duas palavras. Se faltar alguma, me avise antes de seguir)
   npm install
   npx prisma migrate deploy
   npx prisma generate
   npm run build
   cd ../autogestao-frontend
   npm install
   npm run build
   pm2 restart all     (só se os dois builds terminarem sem erro)

Depois siga o GUIA-META.txt para conectar o número.
